# Portfólio

Site estático (HTML + CSS + JS), sem build.

## Como editar
Abra `index.html` e altere só o trecho entre `EDITE SÓ AQUI` e `FIM da área de edição`.
Para adicionar uma experiência, copie um bloco `<article class="job">`.

## Ver no computador
Dê dois cliques em `index.html`.

## Publicar (GitHub Pages)
Repositório → Settings → Pages → Branch `main` / pasta `/ (root)`.
Cada commit/edição no GitHub atualiza o site em ~1 minuto.
